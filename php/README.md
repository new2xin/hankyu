# PHPでの車両位置表示

PHP 8.2以降とcURL拡張を使用します。サーバーは阪急APIへの問い合わせを受け持ち、ブラウザーへ認証ヘッダーを返しません。

## 起動

Windowsではこのディレクトリの `run.bat` を実行し、次のアドレスを開きます。

```text
http://127.0.0.1:18732/
```

手動で起動する場合は、PHPの組み込みWebサーバーから `public` を公開し、`router.php` をルーターに指定してください。

## 取得データ

- `GET /api/lines` は路線と駅の定義を返します。
- `GET /api/positions?line_id=1` は指定路線の車両位置を取得します。指定できる路線IDは1〜10です。
- 阪急からの成功応答はJSONファイルとして保存されます。
- APIアクセス記録は日付単位のJSON Lines形式で追記します。

車両位置の応答は `timestamp`、`state`、`positions` を含むJSONです。保存先は公開ルートの外側に置きます。XREAでは保存ディレクトリへのHTTPアクセスを拒否してください。

共通トークンはサーバー側で設定します。`HANKYU_APP_AUTH_TOKEN` 環境変数を指定した場合は、その値を使います。環境変数がなければアプリに埋め込まれていた共通トークンを読みます。

APIとAPKの解析については、アプリのトップページから[解析ノート](../docs/analysis.md)を参照してください。
