# 阪急 車両位置 Web

阪急沿線アプリの車両位置データを使い、路線と駅、駅間を走る列車、行先と進行方向を表示する非公式のWebアプリです。

公開ページ: [阪急 車両位置](https://xn--c5r.jp/hankyu/)

## APKを調べて分かったこと

[阪急沿線アプリの解析ノート](docs/analysis.md)では、Android内で車両位置画面を開くクラスとメソッド、WebViewが通信するAPI、認証ヘッダー、レスポンスJSONの形を解説しています。アプリの構造とAPI応答を結びつけて読み進められます。

## 起動

Windowsでは `run.bat` を実行してください。Python 3とPHP 8以上を使うローカル版を用意しています。Python版は標準ライブラリだけで動きます。PHP版はcURL拡張を使います。

ブラウザーで開くアドレスは次の通りです。

```text
http://127.0.0.1:18731/
http://127.0.0.1:18732/
```

車両位置を取得するAPIトークンは、アプリに固定値として含まれていた共通トークンです。値が個人ログインの情報ではないこと、Web APIへサーバーから接続する仕組み、有効期間については解析ノートで説明しています。
